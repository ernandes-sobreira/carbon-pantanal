# LAKE-C

Aplicação web progressiva para registro offline em campo da dinâmica de carbono em lagoas pantaneiras.

- Os dados são salvos localmente no navegador do aparelho (IndexedDB).
- A aplicação pode ser instalada como atalho em celular/tablet após abertura por HTTPS.
- O protocolo permite adicionar/remover compartimentos, variáveis e itens de checklist.
- Cada observação mantém lagoa, ponto, réplica e medição em estrutura hierárquica.
- Exporta JSON para backup/importação e CSV para processamento.

**Sincronização em nuvem:** não habilitada nesta versão. Para sincronizar entre aparelhos é necessário ligar a um banco autenticado e configurar permissões. Não inserir chaves administrativas no frontend.
